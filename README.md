## 🎯 Goal
Go from DSA beginner to solving Easy and Medium problems confidently in Python, covering arrays, hashing, two pointers, sliding window, linked lists, stacks, binary search, trees, graphs, backtracking, DP and greedy.

## 📏 Rules
1. **Approach first.** Write the approach in words before writing code.
2. **Complexity always.** Every solution states its time and space complexity.
3. **Hints, not solutions.** If I read a solution, I mark it and redo it from scratch later.
4. **Notes every day.** Every day gets notes in `notes/dayXX.md`.
5. **Explain it.** Explain each day's topic in 2 minutes in Kannada or English.
6. **Push every day.** No day ends without a commit.

## 📁 Structure
```
namma-dsa/
├── dayXX/                       # solutions for day XX
│   └── lcNUMBER_problem_name.py # one file per LeetCode problem
├── notes/
│   └── dayXX.md                 # notes for day XX
└── TEMPLATE.py                  # template every solution file follows
```
